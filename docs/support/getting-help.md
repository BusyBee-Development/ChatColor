# Getting Help

Still stuck after checking [Common Issues](common-issues.md) and the [FAQ](faq.md)?

1. **Run `/color debug`** as the affected player, reproduce the issue, and copy the console
   output — see [Chat Compatibility](../integrations/chat-compatibility.md) for how to read it.
   Having this trace ready is the single most useful thing you can bring to a support request.
2. **Note your platform details:** server software and version (Paper/Spigot), Java version, and
   which other chat-related plugins are installed (EssentialsChat, LPC, DiscordSRV, etc.).
3. **Check the startup log** for the `Chat hook:` line and any `Migration Summary` block from a
   recent update — both are described in [Installation](../getting-started/installation.md) and
   [Configuration](../configuration/configuration.md).

Reach out to BusyBee Development with that information through your usual support channel.
