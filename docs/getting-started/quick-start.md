Setting up **ChatColor** takes less than a minute.

1. **Download** the latest `ChatColor.jar`.
2. **Drop it** into your server's `plugins/` folder.
3. **Restart** your server.
4. Done — players can now run `/color` to open the selector GUI.

Need the full requirements or platform support matrix first? See
[Requirements](requirements.md). For the detailed walkthrough (verifying the install, updating,
troubleshooting), see [Installation](installation.md).
